🔑 AI Provider

Point Jarvis at any OpenAI-compatible endpoint and supply your own key. Works with Gemini, OpenAI, Groq, Together, OpenRouter, or anything you self-host (Ollama, LM Studio, llama.cpp). Saved to config.json and applied on your next message.

Chat and reasoning

Embeddings

Used to find relevant memories and to narrow the tool list before choosing one. This must be an endpoint that serves /v1/embeddings — a chat-only API will not do, and the failure is silent: recall and tool choice quietly get worse. Leave the provider blank to reuse the chat provider above.

Speech recognition

Local Whisper runs on this machine and uploads nothing. A remote endpoint is faster, and your recorded speech goes to whoever runs it. Local is used automatically whenever a remote one fails, so this can never stop transcription working.

🔌 Connections

MCP servers give Jarvis new tools — Home Assistant, GitHub, Slack, your filesystem, a database. Anything added here is written to config.json and picked up on the next conversation.

🌍 Browse the public registry

Thousands of servers published by whoever wrote them. The registry proves the publisher controls the namespace (a GitHub account, or a domain). That says who published it, not that the code is safe or that anyone has reviewed it. Treat these as you would any software off the internet.

⚙️ Add a server manually

Pin an exact version. A package without one (@latest, or no version at all) is refused at launch, because it hands whoever controls that package a fresh run of their code every time Jarvis starts.
